# ⚡ 3D Website (Scroll Animation)

> Converts video into image frames and renders them as a scroll-driven animation in the browser

---

## 📌 Overview

A simple experimental project that creates a smooth scroll-based animation by converting a video into sequential image frames and rendering them using JavaScript.

---

## 🚀 Features

* Frame-by-frame animation using WebP images
* Scroll-controlled playback
* Minimal UI with centered text overlay

---

## ⚙️ How It Works

1. Video is converted into image frames
2. Frames are stored in the `/frames` folder
3. JavaScript updates frames based on scroll position
4. Creates a smooth animation effect

---

## 🛠️ Tech Stack

HTML • CSS • JavaScript • WebP

---

## ▶️ Getting Started

```bash
git clone https://github.com/Sai-shashank-2005/3d-website.git
cd 3d-website
```

Open `index.html` in your browser
